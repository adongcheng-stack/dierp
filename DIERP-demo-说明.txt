# DIERP ERP 演示环境使用说明

本压缩包是**不连接数据库、纯前端内存数据**的可交互演示版本，已内置演示数据快照，所有增删改操作仅在当前浏览器生效（写入 localStorage，刷新不丢）。

---

## 解压后怎么用？

压缩包内包含两种打开方式：

### 方式一：单文件（推荐，发给客户/评审最方便）

直接双击 **`DIERP-demo.html`** 即可在浏览器打开，**无需任何服务器或网络**。
所有内容（页面、样式、脚本、数据）已内联进这一个文件。

- 登录账号：任意已建账号（如 `admin`），密码统一为 **`admin123`**
- 关闭浏览器前，右上角头像菜单里有「**重置演示数据**」，可一键清空本次所有改动并恢复初始快照

### 方式二：静态目录（适合挂到任意静态托管/Nginx）

`dist-demo/` 是独立的静态演示包：
- 用任意静态服务器指向 `dist-demo` 目录即可
- 本项目内可用：`cd dist-demo && npx http-server -p 8080`
- 或通过 Vite：`cd frontend && npm run preview:mock`
- 使用 hash 路由，直接托管/双击均可

## 特点说明

- **纯前端**：不发起任何后端/数据库请求，离线可用。
- **可交互**：新建/编辑/审批/下达/完成/关闭/发货/签收/对账/领料等操作均生效。
- **可持久化**：操作写入浏览器 localStorage，刷新不丢；提供「重置演示数据」入口恢复初始状态。
- **共享代码**：与真实版同一套前端源码，通过 `VITE_MOCK` 开关切换，演示数据结构真实接口一致。

npm run preview:mock
