# P1 收口与 P2（本体模型驱动）实施计划

## Context

W1.5 A4 异常解读已交付并通过回归，但收口检查发现两类问题：AI 异常解读与问数结果直接把枚举码（`SHORTAGE`、`CRITICAL`、`RAW`）呈现给用户；同时缺少面向使用者的交付说明。用户要求先完成 P1 收口并全量验证，再按本体模型驱动推进 P2（先 MCP Server，后 ERP↔MES 语义映射 v1）。核心约束：枚举、语义、权限、形状只能以本体/模型元数据为唯一事实源，不新建硬编码标签字典，不放宽断言，不硬编码旁路。
