- **后置条件**：用例执行后系统的状态

## 详细用例描述

### UC-SD-001: 创建客户

**用例编号**：UC-SD-001  
**用例名称**：创建客户  
**用例参与者**：销售员（主要）  
**用例概述**：销售员创建新客户主数据，包含客户基本信息、多个合作属性、多个地址信息、多个联系人信息、销售数据等。客户创建后状态为DRAFT，需要经过审批流程才能激活使用。  
**触发条件**：销售员需要为新客户建立档案，点击"创建客户"按钮或菜单项。  
**前置条件**：
- 用户已登录系统
- 用户具有SALES角色

**基本流程**：
1. 销售员选择"创建客户"
2. 系统显示客户创建表单
3. 销售员填写客户基本信息：
   - 客户ID（必填）
   - 公司法定全称（必填）
   - 常用商号/简称（必填）
   - 客户状态（默认为DRAFT）
   - 信用额度（可选）
4. 销售员添加客户地址（可选）：
   - 地址类型（发货地址/账单地址）
   - 国家、省份、城市、详细地址
   - 是否默认地址
5. 销售员添加客户联系人（可选）：
   - 姓名、角色、部门、电话、邮箱
6. 销售员添加客户合作属性（可选）：
   - 合作类型、合作开始日期
7. 销售员添加客户销售数据（可选）：
   - 销售区域、销售渠道
8. 销售员点击"保存"
9. 系统验证必填字段
10. 系统创建客户记录，状态为DRAFT
11. 系统显示"客户创建成功"消息

**扩展流程**：
- 3a. 客户ID已存在
  - 3a.1 系统显示"客户ID已存在"错误消息
  - 3a.2 用例结束
- 9a. 必填字段验证失败
  - 9a.1 系统显示验证错误消息
  - 9a.2 返回步骤3

**后置条件**：
- 客户记录已创建，状态为DRAFT
- 客户可以提交审批

**特殊需求**：
- BR-SD-001: 客户状态必须经过审批流程：DRAFT → PENDING_APPROVAL → ACTIVE
- BR-SD-003: 客户可以有多个地址，但只能有一个默认发货地址和一个默认账单地址
- 客户ID必须唯一，系统需要验证客户ID的唯一性
- 支持添加多个地址、联系人和合作属性

### UC-SD-002: 审批客户

**用例编号**：UC-SD-002  
**用例名称**：审批客户  
**用例参与者**：销售经理（主要）  
**用例概述**：销售经理审核销售员创建的客户资料，审批通过后客户状态从PENDING_APPROVAL更新为ACTIVE；审批拒绝时客户状态退回DRAFT并记录原因。  
**触发条件**：销售经理在待审批客户列表中选择客户，点击"审批"或"拒绝"。  
**前置条件**：
- 用户已登录系统
- 用户具有SALES_MANAGER角色
- 客户状态为PENDING_APPROVAL

**基本流程**：
1. 销售经理选择待审批客户
2. 系统显示客户详情与历史
3. 销售经理查看信息，选择"通过"
4. 系统将客户状态更新为ACTIVE
5. 系统记录审批人、审批时间
6. 系统提示"客户已审批通过"

**扩展流程**：
- 3a. 选择"拒绝"
  - 3a.1 系统要求填写拒绝原因（必填）
  - 3a.2 系统将客户状态更新为DRAFT
  - 3a.3 系统记录审批历史和拒绝原因
  - 3a.4 系统提示"客户已被拒绝，退回草稿"

**后置条件**：
- 审批通过：客户状态为ACTIVE，可在后续流程使用
- 审批拒绝：客户状态为DRAFT，销售员可修改后再次提交

**特殊需求**：
- BR-SD-001: 客户状态审批流 DRAFT → PENDING_APPROVAL → ACTIVE
- 拒绝时必须填写原因并记录审批历史

### UC-SD-003: 创建本厂编号映射

**用例编号**：UC-SD-003  
**用例名称**：创建本厂编号映射  
**用例参与者**：销售员/工程师（主要）  
**用例概述**：为客户的物料建立本厂编号与产品主数据的映射，用于销售订单快速引用。若不存在产品主数据，系统提示由ENG模块创建。  
**触发条件**：销售员或工程师在客户资料或订单创建过程中需要建立本厂编号映射，点击"创建映射"。  
**前置条件**：
- 用户已登录系统
- 用户具有SALES或ENGINEER角色
- 客户存在且状态为ACTIVE

**基本流程**：
1. 用户选择客户并点击"创建映射"
2. 系统展示映射表单
3. 用户填写本厂编号（14位）、物料编码(material_code)、生产版本（可选）
4. 系统校验本厂编号格式、本厂编号唯一性（同客户）
5. 系统校验物料编码存在且为产品主数据(FG)
6. 用户点击"保存"
7. 系统创建映射记录

**扩展流程**：
- 4a. 本厂编号格式不正确
  - 4a.1 系统提示"本厂编号格式错误"
  - 4a.2 返回步骤3
- 5a. 物料编码不存在
  - 5a.1 系统提示"物料不存在，请联系ENG创建产品主数据"
  - 5a.2 用例结束

**后置条件**：
- 映射记录已创建，可在销售订单中自动带出material_code/production_version

**特殊需求**：
- 本厂编号为14位，且在同一客户下唯一
- 仅允许映射成品(FG)类型物料
