## 详细用例描述

### UC-PP-005: 创建工序报工

**用例编号**：UC-PP-005  
**用例名称**：创建工序报工  
**用例参与者**：生产人员（主要）  
**用例概述**：生产人员记录工序完成情况，包含完成数量、良品数量、不良品数量、工时等。系统根据生产订单/工单号自动查询关联的LOT卡（一个生产订单/工单对应一个LOT卡，1:1关系），并自动填充报工单中的LOT卡号字段（只读、不可修改）。如果找不到LOT卡，不允许保存报工。报工后系统更新生产进度，如果所有工序都已报工完成，生产订单/工单状态更新为COMPLETED。  
**触发条件**：生产订单/工单状态为RELEASED或IN_PRODUCTION，生产人员完成某个工序后，需要记录报工信息，点击"创建工序报工"按钮或菜单项。  
**前置条件**：
- 用户已登录系统
- 用户具有PRODUCTION角色
- 生产订单状态为RELEASED或IN_PRODUCTION
- 生产订单未完成

**基本流程**：
1. 生产人员选择"创建工序报工"
2. 系统显示工序报工创建表单
3. 系统显示可报工的生产订单/工单列表（排除已完成、已关闭、已取消的订单）
4. 生产人员选择生产订单/工单（必填）
5. 系统获取生产订单/工单信息
6. 系统根据生产订单/工单号自动查询关联的LOT卡（一个生产订单/工单对应一个LOT卡，1:1关系）
7. 系统自动填充报工单中的LOT卡号字段（只读、不可修改）
8. 如果找不到LOT卡，系统不允许保存报工
9. 系统获取生产订单/工单关联的工艺路线
10. 系统获取工艺路线的工序列表
11. 系统显示工序列表
12. 生产人员选择工序（必填）
13. 系统显示工序信息（工序名称、工作中心等）
14. 生产人员填写报工信息：
    - 报工数量（必填）
    - 良品数量（必填）
    - 报废数量（可选）
    - 实际调机时间（可选，分钟）
    - 实际机器时间（可选，分钟）
    - 实际人工时间（可选，分钟）
15. 生产人员点击"保存"
16. 系统验证必填字段
17. 系统验证报工数量不超过生产订单/工单剩余数量
18. 系统创建工序报工记录，状态为PENDING
19. 系统更新生产进度
20. 系统判断是否所有工序都已报工完成：
    - 如果是，将生产订单/工单状态更新为COMPLETED
    - 如果否，将生产订单/工单状态更新为IN_PRODUCTION（如果当前状态是RELEASED）
21. 系统同步销售订单状态（根据生产订单/工单状态）
22. 系统显示"工序报工创建成功"消息

**扩展流程**：
- 3a. 没有可报工的生产订单/工单
  - 3a.1 系统显示"暂无可报工的生产订单/工单"提示消息
  - 3a.2 用例结束
- 8a. 找不到LOT卡
  - 8a.1 系统显示"找不到关联的LOT卡，不允许保存报工"错误消息
  - 8a.2 用例结束
- 10a. 工艺路线没有工序
  - 10a.1 系统显示"该生产订单/工单的物料没有对应的工艺路线或工序"提示消息
  - 10a.2 用例结束
- 13a. 必填字段验证失败
  - 13a.1 系统显示验证错误消息
  - 13a.2 返回步骤11
- 14a. 报工数量超过生产订单剩余数量
  - 14a.1 系统显示"报工数量不能超过生产订单剩余数量"错误消息
  - 14a.2 返回步骤11

**后置条件**：
- 工序报工记录已创建
- 生产订单/工单状态可能更新为COMPLETED或IN_PRODUCTION
- 销售订单状态可能同步更新

**特殊需求**：
- BR-PP-011: 只有RELEASED或IN_PRODUCTION状态的生产订单/工单才能进行工序报工
- BR-PP-012: 报工数量不能超过生产订单/工单的剩余数量
- BR-PP-013: 报工后会自动更新生产进度
- BR-PP-014: 所有工序报工完成后，生产订单/工单状态变为COMPLETED
- BR-PP-015: 新建工序报工时，生产订单/工单列表排除已完成、已关闭和已取消的订单
- BR-PP-016: 系统根据生产订单/工单号自动查询关联的LOT卡（1:1关系），并自动填充报工单中的LOT卡号字段（只读、不可修改）
- BR-PP-017: 如果找不到LOT卡，不允许保存报工
- BR-PP-006: 生产订单/工单状态变化时，会自动同步销售订单状态

### UC-PP-006: 更新工序报工

**用例编号**：UC-PP-006  
**用例名称**：更新工序报工  
**用例参与者**：生产人员（主要）  
**用例概述**：生产人员在报工记录处于PENDING/IN_REVIEW状态时更新报工数量、工时、缺陷等信息，用于纠正录入错误。  
**触发条件**：生产人员在报工详情页点击"编辑"。  
**前置条件**：
- 用户已登录系统
- 用户具有PRODUCTION角色
- 报工记录存在且允许编辑（未终结）

**基本流程**：
1. 生产人员选择报工记录并点击"编辑"
2. 系统展示报工信息
3. 生产人员修改允许变更的字段（数量、工时、缺陷等）
4. 系统校验数量和格式
5. 生产人员点击"保存"
6. 系统更新报工记录并重新计算进度（如需）

**扩展流程**：
- 4a. 校验失败
  - 4a.1 系统提示错误并返回编辑

**后置条件**：
- 报工记录已更新，相关进度数据已同步

**特殊需求**：
- 已完结/审核通过的报工不可直接修改，需走更正/追加流程
