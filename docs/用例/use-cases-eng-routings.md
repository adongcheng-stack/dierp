## 详细用例描述

### UC-ENG-006: 创建工艺路线

**用例编号**：UC-ENG-006  
**用例名称**：创建工艺路线  
**用例参与者**：工程师（主要）  
**优先级**：高  
**前置条件**：
- 用户已登录系统
- 用户具有ENGINEER角色
- 父项产品主数据已存在（如果不存在，系统提示用户创建）

**基本流程**：
1. 工程师选择"创建工艺路线"
2. 系统显示工艺路线创建表单
3. 工程师选择父项产品（必填，通过本厂编号选择）
4. 系统验证产品主数据存在（如果本厂编号对应的产品主数据不存在，系统提示用户创建）
5. 工程师填写工艺路线基本信息：
   - 工艺路线ID（必填，系统自动生成或手动输入）
   - 版本号（必填）
   - 基础单位（默认PNL）
   - 基数（默认1）
   - 每拼板单元数（必填）
   - 拼板尺寸（可选）
   - 生效日期（必填）
   - 失效日期（可选）
6. 工程师添加工序：
   - 工序号（必填，如0010, 0020）
   - 工序代码（必填）
   - 工序名称（必填）
   - 工序类型（internal/external/quality）
   - 工作中心（必填，如果是internal类型）
   - 时间参数（setup_time, machine_time, labor_time）
   - 控制逻辑（cost_relevant, scheduling_relevant等）
   - 外协参数（如果是external类型）
   - 质检参数（如果是quality类型）
7. 工程师可以添加多个工序
8. 工程师可以调整工序顺序
9. 工程师点击"保存"
10. 系统验证必填字段
11. 系统验证工作中心存在（如果是internal类型）
12. 系统创建工艺路线记录，状态为DRAFT
13. 系统创建工序记录
14. 系统显示"工艺路线创建成功"消息

**扩展流程**：
- 4a. 物料不存在
  - 4a.1 系统显示"物料不存在"错误消息
  - 4a.2 返回步骤3
- 10a. 必填字段验证失败
  - 10a.1 系统显示验证错误消息
  - 10a.2 返回步骤5
- 11a. 工作中心不存在
  - 11a.1 系统显示"工作中心不存在"错误消息
  - 11a.2 返回步骤6

**后置条件**：
- 工艺路线记录已创建，状态为DRAFT
- 工序记录已创建
- 工艺路线可以提交审批

**特殊需求**：
- BR-ENG-010: 工艺路线必须经过审批流程：DRAFT → RELEASED
- BR-ENG-013: 工艺路线的基础单位通常为PNL（拼板），用于PCB行业
- BR-ENG-014: 工序按operation_no排序执行

### UC-ENG-007: 更新工艺路线

**用例编号**：UC-ENG-007  
**用例名称**：更新工艺路线  
**用例参与者**：工程师（主要）  
**用例概述**：工程师在工艺路线DRAFT状态下更新工艺路线及工序信息（工序号、工作中心、时间参数等），用于修正工艺设计。  
**触发条件**：工程师在工艺路线详情页点击"编辑"。  
**前置条件**：
- 用户已登录系统
- 用户具有ENGINEER角色
- 工艺路线状态为DRAFT

**基本流程**：
1. 工程师点击"编辑工艺路线"
2. 系统显示工艺路线及工序列表
3. 工程师修改允许变更的字段或工序
4. 系统校验必填字段、工序顺序、工作中心合法性
5. 工程师点击"保存"
6. 系统更新工艺路线记录

**扩展流程**：
- 4a. 工序为空或校验失败
  - 4a.1 系统提示错误并返回编辑

**后置条件**：
- 工艺路线记录已更新

**特殊需求**：
- RELEASED状态需创建新版本而非直接修改

### UC-ENG-008: 发布工艺路线

**用例编号**：UC-ENG-008  
**用例名称**：发布工艺路线  
**用例参与者**：工程师（主要）  
**用例概述**：工程师发布工艺路线，将工艺路线状态从DRAFT更新为RELEASED。只有RELEASED状态的工艺路线才能用于生产版本。  
**触发条件**：工艺路线状态为DRAFT，工程师需要发布工艺路线，点击"发布"按钮。  
**前置条件**：
- 用户已登录系统
- 用户具有ENGINEER角色
- 工艺路线状态为DRAFT

**基本流程**：
1. 工程师选择工艺路线
2. 工程师点击"发布"
3. 系统验证工艺路线状态为DRAFT
4. 系统验证工艺路线必填字段完整
5. 系统验证工序不为空
6. 系统将工艺路线状态更新为RELEASED
7. 系统显示"工艺路线已发布"消息

**扩展流程**：
- 3a. 工艺路线状态不是DRAFT
  - 3a.1 系统显示"工艺路线状态无效，无法发布"错误消息
  - 3a.2 用例结束
- 4a. 必填字段不完整
  - 4a.1 系统显示"请填写所有必填字段"错误消息
  - 4a.2 用例结束
- 5a. 工序为空
  - 5a.1 系统显示"工序不能为空"错误消息
  - 5a.2 用例结束

**后置条件**：
- 工艺路线状态为RELEASED
- 工艺路线可以用于生产版本

**特殊需求**：
- BR-ENG-011: 只有RELEASED状态的工艺路线才能用于生产版本
