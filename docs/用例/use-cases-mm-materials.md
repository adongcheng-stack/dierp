# 某某ERP系统 - 物料主数据用例

## 文档说明

**版本：** v1.5  
**创建日期：** 2025-12-12  
**最后更新：** 2025-01-XX  
**模块：** MM（物料管理）

本文档描述了某某ERP系统物料主数据管理模块的用例，包括参与者、用例列表和详细用例描述。

每个用例包含以下字段：
- **用例编号**：唯一标识用例的编号
- **用例名称**：用例的中文名称
- **用例参与者**：参与用例的主要和次要参与者
- **用例概述**：用例的功能概述和业务价值
- **触发条件**：启动用例的条件或事件
- **前置条件**：用例执行前必须满足的条件
- **基本流程**：用例的主要执行步骤
- **扩展流程**：用例的异常处理和备选路径
- **后置条件**：用例执行后系统的状态
- **特殊需求**：用例的特殊业务规则、约束条件或非功能性需求

## 详细用例描述

### UC-MM-002: 查看物料库存

**用例编号**：UC-MM-002  
**用例名称**：查看物料库存  
**用例参与者**：物料管理员/生产人员（主要）  
**用例概述**：查询物料当前库存、在途量、可用量等信息，支持按物料编码、仓库等条件筛选，为领料与计划提供依据。  
**触发条件**：用户在物料管理中点击"查看库存"或在领料/生产界面查看库存。  
**前置条件**：
- 用户已登录系统
- 用户具有WAREHOUSE或PRODUCTION角色

**基本流程**：
1. 用户进入"查看物料库存"
2. 用户输入查询条件（物料编码、仓库等，可选）
3. 用户点击"查询"
4. 系统展示库存列表，含当前库存、可用量、在途量

**扩展流程**：
- 3a. 查询结果为空
  - 3a.1 系统提示"无符合条件的库存"

**后置条件**：
- 展示查询结果供用户参考

**特殊需求**：
- 库存数据需实时或准实时

---

### UC-MM-003: 查看物料事务历史

**用例编号**：UC-MM-003  
**用例名称**：查看物料事务历史  
**用例参与者**：物料管理员（主要）  
**用例概述**：查看物料出入库历史（MaterialTransaction），包括领料、退料、入库等记录，支持筛选与分页。  
**触发条件**：物料管理员在库存管理中点击"事务历史"。  
**前置条件**：
- 用户已登录系统
- 用户具有WAREHOUSE角色

**基本流程**：
1. 用户进入"物料事务历史"
2. 输入筛选条件（物料编码、类型、时间范围等，可选）
3. 点击"查询"
4. 系统展示事务历史列表，支持分页

**扩展流程**：
- 3a. 无记录
  - 3a.1 系统提示"无符合条件的记录"

**后置条件**：
- 展示物料事务历史

**特殊需求**：
- 事务历史需包含数量、单位、仓库、来源/去向、关联单据等字段
