## 详细用例描述

### UC-ENG-014: 创建生产版本

**用例编号**：UC-ENG-014  
**用例名称**：创建生产版本  
**用例参与者**：工程师（主要）  
**用例概述**：工程师将BOM和工艺路线组合，建立生产版本。BOM和工艺路线准备可以并行进行，无依赖关系。生产版本建立必须等待BOM和工艺路线都准备好，如果任一准备失败，生产版本建立失败，提示用户。MI在创建生产版本时是可选的，但在发布生产版本时是必选的。  
**触发条件**：BOM和工艺路线都已存在且已发布，工程师需要建立生产版本，点击"创建生产版本"按钮或菜单项。  
**前置条件**：
- 用户已登录系统
- 用户具有ENGINEER角色
- 物料已存在
- BOM状态为RELEASED
- 工艺路线状态为RELEASED

**基本流程**：
1. 工程师选择"创建生产版本"
2. 系统显示生产版本创建表单
3. 工程师选择物料（必填）
4. 系统验证物料存在
5. 工程师选择BOM（必填）
6. 系统验证BOM状态为RELEASED
7. 系统验证BOM的parent_material_code与选择的物料匹配
8. 工程师选择工艺路线（必填）
9. 系统验证工艺路线状态为RELEASED
10. 系统验证工艺路线的material_code与选择的物料匹配
11. 工程师选择MI（可选）
12. 如果选择了MI：
    - 12a. 系统验证MI状态为RELEASED（可选，发布时必选）
13. 工程师填写生产版本信息：
    - 生产版本ID（必填，系统自动生成或手动输入）
    - 版本号（必填）
    - 生效日期（必填）
    - 失效日期（可选）
14. 工程师点击"保存"
15. 系统验证必填字段
16. 系统创建生产版本记录，状态为ACTIVE
17. 系统显示"生产版本创建成功"消息

**扩展流程**：
- 4a. 物料不存在
  - 4a.1 系统显示"物料不存在"错误消息
  - 4a.2 返回步骤3
- 6a. BOM状态不是RELEASED
  - 6a.1 系统显示"BOM状态必须为RELEASED"错误消息
  - 6a.2 返回步骤5
- 7a. BOM的parent_material_code与选择的物料不匹配
  - 7a.1 系统显示"BOM的父物料与选择的物料不匹配"错误消息
  - 7a.2 返回步骤5
- 9a. 工艺路线状态不是RELEASED
  - 9a.1 系统显示"工艺路线状态必须为RELEASED"错误消息
  - 9a.2 返回步骤8
- 10a. 工艺路线的material_code与选择的物料不匹配
  - 10a.1 系统显示"工艺路线的物料与选择的物料不匹配"错误消息
  - 10a.2 返回步骤8
- 15a. 必填字段验证失败
  - 15a.1 系统显示验证错误消息
  - 15a.2 返回步骤13

**后置条件**：
- 生产版本记录已创建，状态为ACTIVE
- 生产版本可以用于生产订单

**特殊需求**：
- BR-ENG-021: 创建生产版本时，BOM和工艺路线是必选的，MI是可选的
- BR-ENG-023: 只有RELEASED状态的BOM和工艺路线才能用于生产版本

### UC-ENG-015: 更新生产版本

**用例编号**：UC-ENG-015  
**用例名称**：更新生产版本  
**用例参与者**：工程师（主要）  
**用例概述**：工程师在生产版本ACTIVE状态下更新可变更字段（如有效期、备注等），涉及BOM/工艺路线/MI变更需通过创建新版本或重新选择。  
**触发条件**：工程师在生产版本详情页点击"编辑"。  
**前置条件**：
- 用户已登录系统
- 用户具有ENGINEER角色
- 生产版本已存在

**基本流程**：
1. 工程师点击"编辑生产版本"
2. 系统展示生产版本当前信息
3. 工程师编辑允许修改的字段（如失效日期、备注等）
4. 系统校验数据合法性
5. 工程师点击"保存"
6. 系统更新生产版本记录

**扩展流程**：
- 4a. 校验失败
  - 4a.1 系统提示错误并返回编辑

**后置条件**：
- 生产版本记录已更新

**特殊需求**：
- 若需替换BOM/工艺路线/MI，应通过创建新生产版本处理

---

### UC-ENG-016: 发布生产版本

**用例编号**：UC-ENG-016  
**用例名称**：发布生产版本  
**用例参与者**：工程师（主要）  
**用例概述**：工程师发布生产版本，将生产版本从创建状态发布为可用状态。发布生产版本需要MI已制作且MI审核通过，发布后的生产版本可用于生产订单/工单下达。  
**触发条件**：生产版本已创建，MI已创建且已审核通过，工程师需要发布生产版本，点击"发布"按钮。  
**前置条件**：
- 用户已登录系统
- 用户具有ENGINEER角色
- 生产版本已创建
- MI状态为RELEASED

**基本流程**：
1. 工程师选择生产版本
2. 工程师点击"发布"
3. 系统显示发布确认对话框（可编辑）
4. 系统验证MI已关联
5. 系统验证MI状态为RELEASED
6. 工程师确认发布
7. 系统更新生产版本状态（如果需要）
8. 系统显示"生产版本已发布"消息

**扩展流程**：
- 4a. MI未关联
  - 4a.1 系统显示"发布生产版本时，MI是必选的"错误消息
  - 4a.2 用例结束
- 5a. MI状态不是RELEASED
  - 5a.1 系统显示"MI状态必须为RELEASED"错误消息
  - 5a.2 用例结束

**后置条件**：
- 生产版本已发布
- 生产版本可以用于生产订单

**特殊需求**：
- BR-ENG-022: 发布生产版本时，MI是必选的
