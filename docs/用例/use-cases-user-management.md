## 详细用例描述

### UC-USER-001: 创建用户

**用例编号**：UC-USER-001  
**用例名称**：创建用户  
**用例参与者**：系统管理员（主要）  
**用例概述**：系统管理员创建新用户并分配角色，使新员工可以登录系统并使用相应的功能。用户创建时需要设置用户名、邮箱、密码、角色等信息。  
**触发条件**：系统管理员需要创建新用户，点击"创建用户"按钮或菜单项。  
**前置条件**：
- 用户已登录系统
- 用户具有ADMIN角色

**基本流程**：
1. 系统管理员选择"创建用户"
2. 系统显示用户创建表单
3. 系统管理员填写用户信息：
   - 用户名（必填，唯一）
   - 邮箱（必填，唯一）
   - 密码（必填）
   - 全名（可选）
   - 角色（必填）
   - 部门（可选）
   - 电话（可选）
   - 是否激活（默认true）
4. 系统管理员点击"保存"
5. 系统验证必填字段
6. 系统验证用户名和邮箱唯一性
7. 系统对密码进行哈希处理
8. 系统创建用户记录
9. 系统显示"用户创建成功"消息

**扩展流程**：
- 6a. 用户名已存在
  - 6a.1 系统显示"用户名已存在"错误消息
  - 6a.2 返回步骤3
- 6b. 邮箱已存在
  - 6b.1 系统显示"邮箱已存在"错误消息
  - 6b.2 返回步骤3

**后置条件**：
- 用户记录已创建
- 用户可以登录系统

**特殊需求**：
- 用户名和邮箱必须唯一
- 密码必须经过哈希处理存储

### UC-USER-002: 更新用户

**用例编号**：UC-USER-002  
**用例名称**：更新用户  
**用例参与者**：系统管理员（主要）  
**用例概述**：系统管理员更新用户信息，如角色、部门、电话等，可以修改密码。  
**触发条件**：系统管理员需要更新用户信息，点击"编辑用户"按钮。  
**前置条件**：
- 用户已登录系统
- 用户具有ADMIN角色
- 用户已存在

**基本流程**：
1. 系统管理员选择用户
2. 系统管理员点击"编辑"
3. 系统显示用户信息
4. 系统管理员修改允许变更的字段（用户名和邮箱不可改）
5. 系统管理员点击"保存"
6. 系统验证数据合法性
7. 系统更新用户记录
8. 系统显示"用户更新成功"消息

**扩展流程**：
- 6a. 数据验证失败
  - 6a.1 系统显示验证错误消息
  - 6a.2 返回步骤4

**后置条件**：
- 用户记录已更新

**特殊需求**：
- 用户名和邮箱不可修改
- 密码修改需要重新哈希处理

### UC-USER-003: 删除用户

**用例编号**：UC-USER-003  
**用例名称**：删除用户  
**用例参与者**：系统管理员（主要）  
**用例概述**：系统管理员删除用户，将用户从系统中移除。删除用户前需要确认，避免误操作。  
**触发条件**：系统管理员需要删除用户，点击"删除用户"按钮。  
**前置条件**：
- 用户已登录系统
- 用户具有ADMIN角色
- 用户已存在

**基本流程**：
1. 系统管理员选择用户
2. 系统管理员点击"删除"
3. 系统显示删除确认对话框
4. 系统管理员确认删除
5. 系统删除用户记录
6. 系统显示"用户删除成功"消息

**扩展流程**：
- 4a. 系统管理员取消删除
  - 4a.1 用例结束

**后置条件**：
- 用户记录已删除

**特殊需求**：
- 删除操作需要确认，避免误操作
- 删除用户前需要检查用户是否有关联的业务数据

### UC-USER-004: 用户登录

**用例编号**：UC-USER-004  
**用例名称**：用户登录  
**用例参与者**：所有用户（主要）  
**用例概述**：用户使用用户名和密码登录系统，系统验证用户身份并生成访问令牌（JWT），用户获得访问权限后可以访问系统功能。  
**触发条件**：用户需要访问系统，访问系统登录页面，输入用户名和密码后点击"登录"按钮。  
**前置条件**：
- 用户已注册
- 用户账户已激活

**基本流程**：
1. 用户访问系统登录页面
2. 用户输入用户名和密码
3. 用户点击"登录"
4. 系统验证用户名和密码
5. 系统验证用户账户已激活
6. 系统生成访问令牌（JWT）
7. 系统返回访问令牌
8. 用户成功登录系统

**扩展流程**：
- 4a. 用户名或密码错误
  - 4a.1 系统显示"用户名或密码错误"错误消息
  - 4a.2 返回步骤2
- 5a. 用户账户未激活
  - 5a.1 系统显示"用户账户未激活"错误消息
  - 5a.2 用例结束

**后置条件**：
- 用户已登录系统
- 用户获得访问令牌
- 用户可以访问系统功能

**特殊需求**：
- 只有激活的用户才能登录系统
- 访问令牌有过期时间

---

### UC-USER-005: 用户登出

**用例编号**：UC-USER-005  
**用例名称**：用户登出  
**用例参与者**：所有用户（主要）  
**用例概述**：用户登出系统，系统清除用户的访问令牌，用户需要重新登录才能访问系统。  
**触发条件**：用户需要登出系统，点击"登出"按钮。  
**前置条件**：
- 用户已登录系统

**基本流程**：
1. 用户点击"登出"
2. 系统清除用户的访问令牌
3. 系统显示"已登出"消息
4. 用户返回到登录页面

**后置条件**：
- 用户已登出系统
- 访问令牌已清除
- 用户需要重新登录才能访问系统

**特殊需求**：
- 登出后需要清除所有会话信息
