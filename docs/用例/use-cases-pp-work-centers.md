## 详细用例描述

### UC-PP-001: 创建工作中心

**用例编号**：UC-PP-001  
**用例名称**：创建工作中心  
**用例参与者**：工程师（主要）  
**用例概述**：工程师创建工作中心，定义生产能力和基础参数，供工艺路线和排产使用。  
**触发条件**：工程师在工作中心管理中点击"创建工作中心"。  
**前置条件**：
- 用户已登录系统
- 用户具有ENGINEER角色

**基本流程**：
1. 工程师点击"创建工作中心"
2. 系统显示创建表单
3. 工程师填写工作中心代码（唯一）、名称、类型、产能、班次等
4. 系统校验工作中心代码唯一性
5. 工程师点击"保存"
6. 系统创建工作中心记录

**扩展流程**：
- 4a. 工作中心代码已存在
  - 4a.1 系统提示"工作中心代码已存在"
  - 4a.2 返回步骤3

**后置条件**：
- 工作中心记录已创建，可用于工艺路线/排产

**特殊需求**：
- 工作中心代码唯一

---

### UC-PP-002: 更新工作中心

**用例编号**：UC-PP-002  
**用例名称**：更新工作中心  
**用例参与者**：工程师（主要）  
**用例概述**：工程师更新工作中心的名称、产能、类型等参数，不可修改工作中心代码。  
**触发条件**：工程师在工作中心详情页点击"编辑"。  
**前置条件**：
- 用户已登录系统
- 用户具有ENGINEER角色
- 工作中心已存在

**基本流程**：
1. 工程师点击"编辑工作中心"
2. 系统展示工作中心信息
3. 工程师修改允许变更的字段
4. 系统校验数据合法性
5. 工程师点击"保存"
6. 系统更新工作中心记录

**扩展流程**：
- 4a. 校验失败
  - 4a.1 系统提示错误并返回编辑

**后置条件**：
- 工作中心信息已更新

**特殊需求**：
- 工作中心代码不可修改
