# 故障排除指南

## 前端无法连接后端 (ECONNREFUSED)

### 问题现象
前端启动后，访问API时出现 `ECONNREFUSED` 错误，提示无法连接到 `http://localhost:8000`

### 解决方案

#### 1. 检查后端服务是否运行

**Windows PowerShell:**
```powershell
# 检查8000端口是否被占用
netstat -ano | findstr :8000

# 检查Python进程
Get-Process | Where-Object {$_.ProcessName -like "*python*"}
```

**Linux/Mac:**
```bash
# 检查8000端口
lsof -i :8000

# 检查进程
ps aux | grep uvicorn
```

#### 2. 启动后端服务

**从项目根目录启动（推荐）:**
```powershell
# Windows
cd backend
$env:PYTHONPATH = ".."
py -m uvicorn api.main:app --reload --host 0.0.0.0 --port 8000

# Linux/Mac
cd backend
export PYTHONPATH=..
uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```

**或者使用绝对路径:**
```powershell
# Windows
cd D:\CubeGalaxy\hserp\MVP
$env:PYTHONPATH = "D:\CubeGalaxy\hserp\MVP"
cd backend
py -m uvicorn api.main:app --reload
```

#### 3. 检查数据库配置

确保PostgreSQL已安装并运行：

```sql
-- 连接到PostgreSQL
psql -U postgres

-- 创建数据库
CREATE DATABASE hserp_mvp;

-- 检查数据库是否存在
\l
```

检查 `backend/.env` 文件中的数据库连接字符串：
```
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/hserp_mvp
```

**注意：** 请根据实际情况修改用户名、密码和数据库名。

#### 4. 初始化数据库

首次运行需要初始化数据库表：

```powershell
cd backend
py init_db.py
```

如果出现数据库连接错误，请：
1. 确认PostgreSQL服务正在运行
2. 检查 `.env` 文件中的 `DATABASE_URL` 是否正确
3. 确认数据库 `hserp_mvp` 已创建

#### 5. 检查Python模块导入

测试模块是否可以正常导入：

```powershell
cd backend
py -c "import sys; sys.path.insert(0, '..'); from backend.api.main import app; print('OK')"
```

如果出现 `ModuleNotFoundError`，请：
1. 确保从项目根目录运行，或设置 `PYTHONPATH`
2. 检查所有依赖是否已安装：`py -m pip list`

#### 6. 查看详细错误信息

在前台运行后端服务以查看详细错误：

```powershell
cd backend
$env:PYTHONPATH = ".."
py -m uvicorn api.main:app --reload
```

## 常见错误

### 错误1: ModuleNotFoundError: No module named 'backend'

**原因：** Python找不到backend模块

**解决：** 设置PYTHONPATH环境变量
```powershell
# Windows
$env:PYTHONPATH = "D:\CubeGalaxy\hserp\MVP"

# Linux/Mac
export PYTHONPATH=/path/to/MVP
```

### 错误2: 数据库连接失败

**原因：** PostgreSQL未运行或连接信息错误

**解决：**
1. 启动PostgreSQL服务
2. 检查 `.env` 文件中的 `DATABASE_URL`
3. 确认数据库已创建

### 错误3: 端口8000已被占用

**原因：** 另一个程序正在使用8000端口

**解决：**
```powershell
# 查找占用端口的进程
netstat -ano | findstr :8000

# 使用其他端口
py -m uvicorn api.main:app --reload --port 8001
```

然后修改 `frontend/vite.config.ts` 中的代理端口。

- [ ] `backend/.env` 文件已创建并配置正确
- [ ] Python依赖已安装 (`py -m pip install -r requirements.txt`)
