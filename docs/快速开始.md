# 快速开始指南

## 第一步：安装PostgreSQL

1. 下载PostgreSQL：https://www.postgresql.org/download/windows/
2. 安装时记住设置的postgres用户密码
3. 确保PostgreSQL服务正在运行

## 第二步：创建数据库

### 方法1：使用pgAdmin（最简单，推荐）

1. 打开pgAdmin
2. 连接到PostgreSQL服务器
3. 右键点击"Databases" → "Create" → "Database"
4. 输入数据库名：`hserp_mvp`
5. 点击"Save"

### 方法2：使用psql命令行

找到PostgreSQL的bin目录（通常在 `C:\Program Files\PostgreSQL\<version>\bin`），然后：

```powershell
# 使用完整路径
& "C:\Program Files\PostgreSQL\16\bin\psql.exe" -U postgres

# 在psql提示符下执行
CREATE DATABASE hserp_mvp;
\q
```

### 方法3：使用Python脚本

```powershell
cd backend
py create_database_simple.py
```

然后按提示输入PostgreSQL连接信息。

## 第三步：配置环境变量

在 `backend` 目录下创建 `.env` 文件：

```env
DATABASE_URL=postgresql://postgres:你的密码@localhost:5432/hserp_mvp
SECRET_KEY=your-secret-key-change-in-production
ALGORITHM=HS256
ACCESS_TOKEN_EXPIRE_MINUTES=30
```

**重要：** 将 `你的密码` 替换为PostgreSQL的postgres用户密码。

## 第四步：安装依赖

```powershell
cd backend
py -m pip install -r requirements.txt
```

## 第五步：初始化数据库

```powershell
py init_db.py
```

这将创建所有数据表并创建默认管理员用户。

## 第六步：启动后端服务

```powershell
.\start.ps1
```

或者手动启动：

```powershell
$env:PYTHONPATH = ".."
py -m uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```

## 第七步：启动前端服务

打开新的终端窗口：

```powershell
cd frontend
npm install
npm run dev
```

## 验证安装

1. **后端健康检查：** http://localhost:8000/api/health
2. **API文档：** http://localhost:8000/docs
3. **前端界面：** http://localhost:3000

## 常见问题

### 问题：无法连接到数据库

**解决：**
1. 确认PostgreSQL服务正在运行
2. 检查 `.env` 文件中的密码是否正确
3. 确认数据库 `hserp_mvp` 已创建

### 问题：ModuleNotFoundError

**解决：**
```powershell
# 设置PYTHONPATH
$env:PYTHONPATH = "D:\CubeGalaxy\hserp\MVP"
```

### 问题：前端无法连接后端

**解决：**
1. 确认后端服务已启动（端口8000）
2. 检查后端服务日志
3. 访问 http://localhost:8000/api/health 验证后端是否运行
