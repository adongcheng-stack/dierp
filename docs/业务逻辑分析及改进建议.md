## 二、发现的问题

### 2.1 业务规则验证不完整

#### 问题1：客户信用额度验证不完整

**问题描述**：
- 当前只验证单笔订单金额是否超过信用额度
- 未考虑客户已有的未完成订单总额
- 可能导致客户总订单金额超过信用额度

**影响**：
- 信用风险控制不足
- 可能出现超信用额度发货的情况

**建议解决方案**：
```python
def validate_customer_credit(
    customer_id: str,
    order_amount: Decimal,
    db: Session
) -> bool:
    # 计算当前未完成订单总额
    unpaid_orders = db.query(SalesOrder).filter(
        SalesOrder.customer_id == customer_id,
        SalesOrder.status.in_([
            SalesOrderStatus.DRAFT,
            SalesOrderStatus.PENDING_REVIEW,
            SalesOrderStatus.APPROVED,
            SalesOrderStatus.IN_PRODUCTION
        ]),
        SalesOrder.is_deleted == False
    ).all()
    
    current_unpaid_amount = sum(
        Decimal(str(order.total_amount)) 
        for order in unpaid_orders
    )
    
    # 验证总金额（当前未完成 + 新订单）是否超过信用额度
    total_amount = current_unpaid_amount + order_amount
    if total_amount > credit_limit:
        raise ValidationException(...)
```

**问题描述**：

**影响**：
- 可能出现产能不足的情况

**建议解决方案**：

```python
def validate_work_center_capacity(
    work_center_id: str,
    required_time: Decimal,
    planned_date: date,
    db: Session
) -> bool:
    # 1. 获取工作中心日产能
    work_center = db.query(WorkCenter).filter(...).first()
    daily_capacity = work_center.daily_capacity_minutes  # 需要添加此字段
    
    # 2. 查询计划日期当天的已占用产能
    occupied_orders = db.query(ProductionOrder).filter(
        ProductionOrder.planned_start_date <= planned_date,
        ProductionOrder.planned_finish_date >= planned_date,
        ProductionOrder.status.in_([...])
    ).all()
    
    # 计算已占用产能（需要根据Routing计算）
    occupied_time = calculate_occupied_capacity(occupied_orders, work_center_id)
    
    # 3. 验证可用产能
    available_capacity = daily_capacity - occupied_time
    if required_time > available_capacity:
        raise ValidationException(...)
```

### 2.4 业务规则缺失

#### 问题7：缺少订单状态流转验证

**问题描述**：
- 订单状态变更时，未验证状态流转的合法性
- 例如：DRAFT 不能直接变为 COMPLETED

**影响**：
- 可能出现不合法的状态流转
- 业务流程可能被跳过

**建议解决方案**：
```python
class OrderStatusValidator:
    # 定义合法的状态流转
    ALLOWED_TRANSITIONS = {
        SalesOrderStatus.DRAFT: [SalesOrderStatus.PENDING_REVIEW, SalesOrderStatus.CANCELLED],
        SalesOrderStatus.PENDING_REVIEW: [SalesOrderStatus.APPROVED, SalesOrderStatus.REJECTED],
        SalesOrderStatus.APPROVED: [SalesOrderStatus.IN_PRODUCTION, SalesOrderStatus.CANCELLED],
        # ...
    }
    
    @staticmethod
    def validate_status_transition(
        current_status: str,
        new_status: str
    ) -> bool:
        allowed = OrderStatusValidator.ALLOWED_TRANSITIONS.get(current_status, [])
        if new_status not in allowed:
            raise ValidationException(...)
```

**影响**：

**建议解决方案**：

### 2.5 性能问题

#### 问题9：可能存在N+1查询问题

**问题描述**：
- 在循环中查询数据库，可能导致N+1查询问题
- 例如：验证每个工序的工作中心时，逐个查询

**影响**：
- 查询性能差
- 响应时间慢

**建议解决方案**：
```python
# 批量查询工作中心
work_center_ids = [op.work_center_id for op in operations]
work_centers = db.query(WorkCenter).filter(
    WorkCenter.work_center_id.in_(work_center_ids)
).all()
work_center_map = {wc.work_center_id: wc for wc in work_centers}

# 在循环中使用map
for op in operations:
    work_center = work_center_map.get(op.work_center_id)
```

#### 问题10：缺少缓存机制

**问题描述**：
- 频繁查询的数据（如物料列表、客户列表）没有缓存
- 每次请求都查询数据库

**影响**：
- 数据库压力大
- 响应时间慢

**建议解决方案**：
- 使用Redis缓存热点数据
- 设置合理的缓存过期时间
- 在数据更新时清除相关缓存

### 2.6 并发控制缺失

#### 问题11：缺少乐观锁或悲观锁

**问题描述**：
- 更新操作时，未使用版本号或锁机制
- 可能出现并发更新导致的数据覆盖

**影响**：
- 数据可能被覆盖
- 可能出现"丢失更新"问题

**建议解决方案**：
```python
# 使用乐观锁（版本号）
class SalesOrder(BaseModel):
    version: int = 0  # 版本号字段

def update_sales_order(order_number: str, data: dict, db: Session):
    order = db.query(SalesOrder).filter(
        SalesOrder.order_number == order_number
    ).first()
    
    # 检查版本号
    if data.get("version") != order.version:
        raise ConflictException("数据已被其他用户修改，请刷新后重试")
    
    # 更新数据并增加版本号
    order.version += 1
    # ...
```

## 五、详细改进方案

### 5.1 完善客户信用额度验证

#### 当前实现问题
```python
# 只验证单笔订单金额
if order_amount > credit_limit:
    raise ValidationException(...)
```

#### 改进方案
```python
def validate_customer_credit(
    customer_id: str,
    order_amount: Decimal,
    db: Session
) -> bool:
    customer = db.query(Customer).filter(...).first()
    
    if not customer or not customer.credit_limit:
        return True
    
    credit_limit = Decimal(str(customer.credit_limit))
    
    # 计算当前未完成订单总额
    unpaid_orders = db.query(SalesOrder).filter(
        SalesOrder.customer_id == customer_id,
        SalesOrder.status.in_([
            SalesOrderStatus.DRAFT,
            SalesOrderStatus.PENDING_REVIEW,
            SalesOrderStatus.APPROVED,
            SalesOrderStatus.IN_PRODUCTION
        ]),
        SalesOrder.is_deleted == False
    ).all()
    
    current_unpaid_amount = sum(
        Decimal(str(order.total_amount)) 
        for order in unpaid_orders
    )
    
    # 验证总金额（当前未完成 + 新订单）
    total_amount = current_unpaid_amount + order_amount
    if total_amount > credit_limit:
        raise ValidationException(
            error_code=ErrorCodes.CUSTOMER_CREDIT_EXCEEDED,
            detail=f"订单总金额 {total_amount} 超过客户信用额度 {credit_limit}（当前未完成订单：{current_unpaid_amount}，新订单：{order_amount}）",
            field="order_amount",
            value=float(order_amount)
        )
    
    return True
```

```python
        return True
    
    # 获取工作中心日产能（需要添加此字段到WorkCenter模型）
    daily_capacity = Decimal(str(work_center.daily_capacity_minutes or 480))  # 默认8小时
    
    # 查询计划日期当天的已占用产能
    # 需要根据生产订单的Routing计算每个订单在该工作中心的占用时间
    occupied_time = calculate_daily_occupied_capacity(
        work_center_id=work_center_id,
        planned_date=planned_date,
        db=db
    )
    
    # 验证可用产能
    available_capacity = daily_capacity - occupied_time
    if required_time > available_capacity:
        raise ValidationException(
            error_code=ErrorCodes.WORK_CENTER_CAPACITY_INSUFFICIENT,
            detail=f"工作中心 {work_center_id} 产能不足：需要 {required_time} 分钟，可用 {available_capacity} 分钟（日产能：{daily_capacity}，已占用：{occupied_time}）",
            field="required_time",
            value=float(required_time)
        )
    
    return True

def calculate_daily_occupied_capacity(
    work_center_id: str,
    planned_date: date,
    db: Session
) -> Decimal:
    """计算指定日期工作中心的已占用产能"""
    # 查询该日期有生产活动的订单
    orders = db.query(ProductionOrder).filter(
        ProductionOrder.planned_start_date <= planned_date,
        ProductionOrder.planned_finish_date >= planned_date,
        ProductionOrder.status.in_([
            ProductionOrderStatus.APPROVED,
            ProductionOrderStatus.IN_PRODUCTION
        ])
    ).all()
    
    total_occupied = Decimal(0)
    for order in orders:
        # 获取订单的Routing
        pv = db.query(ProductionVersion).filter(
            ProductionVersion.production_version_id == order.production_version_id
        ).first()
        
        if not pv or not pv.routing_id:
            continue
        
        # 查找该工作中心的工序
        operation = db.query(RoutingOperation).filter(
            RoutingOperation.routing_id == pv.routing_id,
            RoutingOperation.work_center_id == work_center_id
        ).first()
        
        if operation:
            # 计算占用时间
            setup_time = Decimal(str(operation.setup_time or 0))
            machine_time = Decimal(str(operation.machine_time or 0))
            quantity = Decimal(str(order.quantity))
            occupied = setup_time + (machine_time * quantity)
            total_occupied += occupied
    
    return total_occupied
```

```python
def validate_production_order_materials(

def expand_bom_recursive(
    bom_number: str,
    quantity: Decimal,
    base_quantity: Decimal,
    db: Session,
    visited: set = None
) -> Dict[str, Decimal]:
    """递归展开BOM，返回物料需求字典"""
    if visited is None:
        visited = set()
    
    if bom_number in visited:
        # 防止循环引用
        return {}
    
    visited.add(bom_number)
    
    # 获取BOM明细
    bom_items = db.query(BOMItem).filter(
        BOMItem.bom_number == bom_number
    ).all()
    
    material_requirements = {}
    
    for item in bom_items:
        material_code = item.material_code
        item_quantity = Decimal(str(item.quantity))
        scrap_rate = Decimal(str(item.scrap_rate or 0))
        
        # 计算需求量（考虑基数、损耗率）
        base_required = (quantity / base_quantity) * item_quantity
        required_with_scrap = base_required * (1 + scrap_rate / 100)
        
        # 检查子物料是否有BOM（多层级BOM）
        child_bom = db.query(BOM).filter(
            BOM.parent_material_code == material_code,
            BOM.status.in_(["RELEASED", "ACTIVE"])
        ).first()
        
        if child_bom:
            # 递归展开子BOM
            child_requirements = expand_bom_recursive(
                bom_number=child_bom.bom_number,
                quantity=required_with_scrap,
                base_quantity=Decimal(str(child_bom.base_quantity)),
                db=db,
                visited=visited.copy()
            )
            
            # 合并子BOM的物料需求
            for child_material, child_quantity in child_requirements.items():
                material_requirements[child_material] = (
                    material_requirements.get(child_material, Decimal(0)) + child_quantity
                )
        else:
            # 直接物料，累加需求
            material_requirements[material_code] = (
                material_requirements.get(material_code, Decimal(0)) + required_with_scrap
            )
    
    return material_requirements
```
