# 报价单报价模型（Quotation Pricing Model）

**版本：** v1.0  
**最后更新：** 2025-01-XX  
**维护者：** 开发团队

## 1. 概述

报价单报价模型定义了PCB（印制电路板）报价单的价格计算逻辑，包括成本计算、加价规则、工序成本分摊等。该模型支持基于板规格参数、工艺参数、加价选项等进行自动报价计算。

## 3. 计算公式

### 3.1 交货面积计算

```
交货面积 (m²) = (出货长 (mm) × 出货宽 (mm) × 订单数量) / 1,000,000
```

### 3.2 实际投P计算

```
实际投P = max(1, 订单数量)
```

### 3.3 基础成本计算

#### 3.3.1 基础成本/平米

```
基础成本/平米 = 基础成本基准值（如1000元/平米）
```

#### 3.3.2 层数调整系数

```
层数调整系数 = 1.0 + (层数 - 1) × 0.15
```

#### 3.3.3 成本/平米（含层数调整）

```
成本/平米 = 基础成本/平米 × 层数调整系数
```

### 3.4 加价计算

#### 3.4.1 常规加价

```
常规加价/平米 = Σ(常规加价项单价)
```

每个常规加价项（如碳油、蓝胶、高温胶、阻抗要求等）增加固定金额（如50元/平米）。

#### 3.4.2 特殊加价

```
特殊加价/平米 = Σ(特殊加价项单价)
```

- 布尔类型特殊加价项：每个增加固定金额（如100元/平米）
- 数值类型特殊加价项：根据数量计算（如：数量 × 10元/平米）

#### 3.4.3 额外加价

```
额外加价/平米 = 额外加价/M²（直接使用）
```

#### 3.4.4 总加价

```
总加价/平米 = 常规加价/平米 + 特殊加价/平米 + 额外加价/平米
```

#### 3.4.5 最终成本/平米

```
最终成本/平米 = 成本/平米（含层数调整） + 总加价/平米
```

### 3.5 成本PCS计算

```
成本PCS = 最终成本/平米 × (出货长 (mm) × 出货宽 (mm) / 1,000,000)
```

### 3.6 报价价格计算

#### 3.6.1 报价价格/平米

```
报价价格/平米 = 最终成本/平米 × 利润率系数（如1.3，即30%利润）
```

#### 3.6.2 报价价格PCS

```
报价价格PCS = 成本PCS × 利润率系数（如1.3）
```

### 3.7 工程费计算

```
工程费 = 基础工程费（如150元）

如果 层数 > 4:
    工程费 = 200元
如果 层数 > 6:
    工程费 = 250元
```

### 3.8 板材费计算

```
板材费 = 最终成本/平米 × 交货面积 (m²)
```

### 3.9 测试架费用计算

```
如果 测试点数 > 0:
    测试架费用 = 基础测试架费用（如500元）
否则:
    测试架费用 = 0
```

### 3.10 其他费用计算

```
其他费用 = 收客户最低消费（如果设置）
```

### 3.11 最终总价计算

```
最终总价 = 工程费 + 板材费 + 测试架费用 + 其他费用
```

### 3.12 工序成本分摊

工序成本按比例分摊到各个工序，典型工序及成本占比：

| 工序名称 | 成本占比 | 说明 |
|---------|---------|------|
| 开料 | 10% | 基础开料成本 |
| 钻孔 | 15% | 根据SET孔数计算 |
| 电镀 | 20% | 根据层数计算 |
| 线路 | 25% | 根据线宽线距计算 |
| 阻焊 | 15% | 根据阻焊颜色计算 |
| 表面处理 | 10% | 根据表面处理类型计算 |
| 成型 | 5% | 根据锣程计算 |

每个工序的P价格计算：

```
工序P价格 = 最终成本/平米 × 工序成本占比
```

## 4. 业务规则

### 4.1 计算触发规则

1. **实时计算**：用户在报价单表单中修改板规格参数、加价选项时，系统自动触发报价计算
2. **手动计算**：用户点击"计算报价"按钮时，系统执行完整报价计算
3. **保存时计算**：保存报价单时，系统自动计算并保存计算结果

### 4.2 数据验证规则

1. **必填字段验证**：
   - 出货长、出货宽必须大于0
   - 订单数量必须大于0
   - 层数必须大于0

2. **数值范围验证**：
   - 利用率应在0-100%之间
   - 交货面积必须大于0
   - 所有价格字段必须非负

### 4.3 计算精度规则

1. **面积计算**：保留4位小数（m²）
2. **价格计算**：保留4位小数（元）
3. **百分比计算**：保留4位小数（%）
4. **最终总价**：保留2位小数（元）

### 4.4 加价规则

1. **常规加价**：每个选项独立计算，可多选
2. **特殊加价**：支持布尔类型和数值类型，数值类型按数量计算
3. **额外加价**：直接按平米单价计算
4. **最低消费**：如果计算出的总价低于最低消费，按最低消费计

### 4.5 工序成本分摊规则

1. **固定比例**：各工序成本占比固定，总和为100%
2. **面积关联**：工序成本与交货面积关联
3. **参数影响**：部分工序成本受工艺参数影响（如层数、孔数、线宽线距等）

## 5. API接口

### 5.1 临时计算接口

**POST** `/api/sd/quotations/calculate-details`

计算报价明细成本（不需要报价单编号，用于临时计算）。

**请求体**：`QuotationDetailCalculationRequest`

**响应**：`QuotationDetailCalculationResponse`

### 5.2 报价单计算接口

**POST** `/api/sd/quotations/{quotation_number}/calculate-details`

计算指定报价单的报价明细成本。

**路径参数**：
- `quotation_number`：报价单编号

**请求体**：`QuotationDetailCalculationRequest`

**响应**：`QuotationDetailCalculationResponse`

## 6. 数据流转

### 6.1 报价计算流程

```
1. 用户输入板规格参数
   ↓
2. 系统计算交货面积
   ↓
3. 系统计算基础成本（含层数调整）
   ↓
4. 系统计算加价（常规+特殊+额外）
   ↓
5. 系统计算最终成本/平米和成本PCS
   ↓
6. 系统计算报价价格（成本×利润率）
   ↓
7. 系统计算工程费、板材费、测试架、其他费用
   ↓
8. 系统计算最终总价
   ↓
9. 系统分摊工序成本
   ↓
10. 系统返回计算结果并更新报价单
```

### 6.2 数据保存流程

```
1. 用户保存报价单
   ↓
2. 系统验证必填字段
   ↓
3. 系统执行报价计算
   ↓
4. 系统保存报价单主表数据
   ↓
5. 系统保存报价明细工序表数据
   ↓
6. 系统返回保存结果
```

## 7. 扩展说明

### 7.1 可配置参数

以下参数可在系统配置中调整：

- 基础成本/平米基准值
- 层数调整系数（当前为0.15）
- 利润率系数（当前为1.3，即30%利润）
- 常规加价项单价
- 特殊加价项单价
- 工序成本占比
- 工程费阶梯值

### 7.2 未来扩展方向

1. **动态成本计算**：基于历史订单数据、物料价格、工作中心成本等动态计算成本
2. **多币种支持**：支持多币种报价和汇率转换
3. **批量报价**：支持批量产品报价计算
4. **报价模板**：支持保存和复用报价模板
5. **成本分析**：提供成本构成分析和对比功能
6. **价格审批**：集成价格审批流程，支持价格调整审批

## 8. 示例

### 8.1 示例数据

- 订单数量：1000 PCS
- 出货长：100 mm
- 出货宽：80 mm
- 层数：4层
- 测试点数：50

### 8.2 计算过程

1. **交货面积**：
   ```
   交货面积 = (100 × 80 × 1000) / 1,000,000 = 8.0 m²
   ```

2. **基础成本**：
   ```
   基础成本/平米 = 1000元
   层数调整系数 = 1.0 + (4-1) × 0.15 = 1.45
   成本/平米 = 1000 × 1.45 = 1450元
   ```

3. **加价**（假设常规加价50元，特殊加价100元）：
   ```
   总加价/平米 = 50 + 100 = 150元
   最终成本/平米 = 1450 + 150 = 1600元
   ```

4. **成本PCS**：
   ```
   成本PCS = 1600 × (100 × 80 / 1,000,000) = 12.8元
   ```

5. **报价价格**：
   ```
   报价价格/平米 = 1600 × 1.3 = 2080元
   报价价格PCS = 12.8 × 1.3 = 16.64元
   ```

6. **工程费**：
   ```
   工程费 = 150元（4层）
   ```

7. **板材费**：
   ```
   板材费 = 1600 × 8.0 = 12800元
   ```

8. **测试架**：
   ```
   测试架 = 500元（有测试点）
   ```

9. **最终总价**：
   ```
   最终总价 = 150 + 12800 + 500 = 13450元
   ```
