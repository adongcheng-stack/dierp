# 用户与权限管理模块 - 用户管理子模块用户故事

**对应菜单：** `/admin/users`  
**对应用例：** UC-USER-001, UC-USER-002, UC-USER-003, UC-USER-004, UC-USER-005

---

## US-USER-001: 创建用户

**用户故事：**
```
As a 系统管理员
I want 创建新用户并设置角色和权限
So that 用户可以登录系统并执行相应的操作
```

**优先级：** P1  
**验收标准：**
- Given 系统管理员已登录系统
- When 系统管理员创建用户
- Then 系统创建用户记录
- And 系统设置用户名、邮箱、密码、角色等
- And 用户名和邮箱必须唯一
- And 密码需要进行哈希处理

**相关用例：** UC-USER-001

---

## US-USER-002: 更新用户

**用户故事：**
```
As a 系统管理员
I want 更新用户信息
So that 我可以维护用户的准确信息，更新角色和权限
```

**优先级：** P2  
**验收标准：**
- Given 用户已存在
- When 系统管理员更新用户信息
- Then 系统更新用户记录
- And 系统支持更新用户名、邮箱、角色等信息
- And 用户名和邮箱的唯一性验证

**相关用例：** UC-USER-002

---

## US-USER-003: 删除用户

**用户故事：**
```
As a 系统管理员
I want 删除用户
So that 我可以移除不再需要的用户账号
```

**优先级：** P3  
**验收标准：**
- Given 用户已存在
- When 系统管理员删除用户
- Then 系统执行软删除（is_deleted=true）
- And 系统保留用户历史记录

**相关用例：** UC-USER-003

---

## US-USER-004: 用户登录

**用户故事：**
```
As a 所有用户
I want 使用用户名和密码登录系统
So that 我可以访问系统功能，执行我的工作
```

**优先级：** P0  
**验收标准：**
- Given 用户账号已存在且激活
- When 用户输入用户名和密码登录
- Then 系统验证身份并生成JWT令牌
- And 只有激活的用户才能登录
- And 系统记录登录时间和IP地址

**相关用例：** UC-USER-004

---

## US-USER-005: 用户登出

**用户故事：**
```
As a 所有用户
I want 登出系统
So that 我可以安全地结束会话，保护账号安全
```

**优先级：** P2  
**验收标准：**
- Given 用户已登录系统
- When 用户点击登出
- Then 系统清除JWT令牌
- And 用户需要重新登录才能访问系统

**相关用例：** UC-USER-005

---

**用户故事统计：**
- P0（关键）：1个
- P1（高）：1个
- P2（中）：2个
- P3（低）：1个
- 总计：5个
