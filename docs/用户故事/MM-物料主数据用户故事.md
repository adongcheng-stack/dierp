# MM模块 - 物料主数据子模块用户故事

**对应菜单：** `/mm/materials`  
**对应用例：** UC-ENG-002, UC-ENG-002A, UC-MM-002, UC-MM-003

**说明：** 物料主数据管理不显示FG类型的物料（FG类型物料在产品主数据管理中显示）。

---

## US-ENG-002: 创建物料

**用户故事：**
```
As an 工程师
I want 创建物料（非成品类物料，如原材料、半成品等）
So that 我可以维护物料的完整信息，为BOM、库存管理等提供基础数据
```

**优先级：** P0  
**验收标准：**
- Given 工程师已登录系统
- When 工程师创建物料
- Then 系统创建Material记录，material_type不为'FG'
- And 物料编码（material_code）必须唯一
- And 系统不显示成品（FG类型）的物料
- And 系统支持PCB专有属性

**相关用例：** UC-ENG-002

---

## US-MM-002: 查看物料库存

**用户故事：**
```
As a 物料管理员/生产人员
I want 查看物料库存
So that 我可以了解物料的当前库存、在途量、可用量，为领料和计划提供依据
```

**优先级：** P0  
**验收标准：**
- Given 用户已登录系统
- When 用户查看物料库存
- Then 系统显示当前库存、在途量、可用量
- And 系统支持按物料编码、仓库等条件筛选
- And 系统为领料与计划提供依据

**相关用例：** UC-MM-002

---

## US-MM-003: 查看物料事务历史

**用户故事：**
```
As a 物料管理员
I want 查看物料事务历史
So that 我可以了解物料的出入库历史，跟踪物料流动
```

**优先级：** P1  
**验收标准：**
- Given 用户已登录系统
- When 用户查看物料事务历史
- Then 系统显示物料出入库历史（MaterialTransaction）
- And 系统包括领料、退料、入库等记录
- And 系统支持按物料编码、时间等条件筛选

**相关用例：** UC-MM-003

---

**用户故事统计：**
- P0（关键）：2个
- P1（高）：1个
- 总计：3个
