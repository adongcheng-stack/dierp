## US-MM-001: 创建生产领料单

**用户故事：**
```
As a 物料管理员
I want 创建生产领料单，从仓库领料用于生产
So that 生产订单可以获得所需的原材料，系统可以跟踪物料消耗和库存变化
```

**优先级：** P0  
**验收标准：**
- Given 生产订单已存在
- And 生产订单状态为RELEASED或IN_PRODUCTION
- When 物料管理员创建生产领料单
- Then 系统根据生产订单/工单关联的BOM自动生成领料需求
- And 系统实时显示库存信息
- And 当库存不足时，可生成缺料单
- And 领料后自动更新物料库存
- And 系统创建MaterialIssue记录

**相关用例：** UC-MM-001
