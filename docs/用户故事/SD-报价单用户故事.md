## US-SD-004: 创建报价单

**用户故事：**
```
As a 销售员
I want 为客户创建报价单，包含产品信息、数量和价格，并计算报价明细成本
So that 我可以向客户提供正式报价，促进订单成交
```

**优先级：** P0  
**验收标准：**
- Given 客户状态为ACTIVE
- When 销售员创建报价单并填写产品信息（本厂编号、产品名称）
- Then 如果本厂编号对应的产品主数据不存在，SD模块调用ENG模块API自动创建产品主数据，自动创建的产品主数据不需要审核
- And 销售员填写板规格参数、工艺参数、加价选项
- And 销售员点击"计算报价"按钮手动计算报价明细成本
- Then 系统计算报价明细成本（交货面积、成本/平米、成本PCS、报价价格、工程费、板材费、测试架费用等），并生成工序成本明细
- And 系统创建报价单记录，状态为DRAFT
- And 销售员可以添加报价单明细

**相关用例：** UC-SD-004

## US-SD-005: 提交报价单审批

**用户故事：**
```
As a 销售员
I want 提交报价单进行审批
So that 报价单可以经过销售、工程、总经理的审批流程，确保价格合理
```

**优先级：** P0  
**验收标准：**
- Given 报价单状态为DRAFT
- When 销售员提交审批
- Then 系统创建工作流实例
- And 报价单状态更新为PENDING_SALES
- And 销售经理可以审批报价单

**相关用例：** UC-SD-005

## US-SD-006: 审批报价单

**用户故事：**
```
As a 销售经理/工程师/客户经理或总经理
I want 审批报价单（三级审核流程）
So that 我可以确保报价单的价格、技术参数等符合公司政策和客户要求
```

**优先级：** P0  
**验收标准：**
- Given 报价单已提交审批
- When 审批人审批报价单（一级：销售经理，二级：工程师，三级：客户经理或总经理）
- Then 如果是一级审核通过，报价单状态更新为PENDING_ENGINEER
- And 如果是二级审核通过，报价单状态更新为PENDING_ACCOUNT_MANAGER
- And 如果是三级审核通过，报价单状态更新为APPROVED
- And 如果任何一级审核不通过，报价单状态退回DRAFT，退回操作记录审核历史，保存退回原因

**相关用例：** UC-SD-006

## US-SD-007: 重新提交被拒绝的报价单

**用户故事：**
```
As a 销售员
I want 重新提交被拒绝的报价单
So that 我可以根据审批意见修改报价单，重新进入审批流程
```

**优先级：** P1  
**验收标准：**
- Given 报价单状态为DRAFT（退回草稿状态）
- When 销售员修改报价单并重新提交
- Then 系统清除之前的审批信息
- And 报价单状态更新为PENDING_SALES
- And 报价单重新进入三级审核流程

**相关用例：** UC-SD-008

## US-SD-009: 销售员经客户确认报价单

**用户故事：**
```
As a 销售员
I want 与客户确认报价单并在系统中标记客户确认状态
So that 客户确认后的报价单可以转为销售订单
```

**优先级：** P0  
**验收标准：**
- Given 报价单状态为APPROVED（已通过三级审核）
- When 销售员与客户沟通确认报价单
- And 客户确认报价单（线下确认）
- And 销售员在系统中标记"客户已确认"
- Then 报价单可以转为销售订单
- When 客户不确认报价单
- And 销售员在系统中标记"客户不确认"
- Then 报价单状态更新为DRAFT（退回草稿状态），退回操作记录审核历史，保存退回原因
- And 销售员可以修改报价单并重新提交审核

**相关用例：** UC-SD-009
