# ENG模块 - MI管理子模块用户故事

**对应菜单：** `/eng/mis`  
**对应用例：** UC-ENG-009, UC-ENG-010, UC-ENG-011, UC-ENG-012, UC-ENG-013

## US-ENG-009: 创建MI

**用户故事：**
```
As an 工程师
I want 创建MI（制造指令），包含详细的工艺参数和操作指导
So that 生产人员可以按照MI进行生产，确保产品质量和工艺一致性
```

**优先级：** P0  
**验收标准：**
- Given 物料已存在
- When 工程师创建MI
- Then 系统创建MI记录，状态为DRAFT
- And 工程师可以选择工艺路线，系统自动生成MI草稿
- And 工程师可以添加MI指令集列表和描述
- And 工程师可以调整指令集顺序（使用上下箭头）
- And MI内容以JSON格式存储

**相关用例：** UC-ENG-009

---

## US-ENG-010: 基于工艺路线生成MI草稿

**用户故事：**
```
As an 工程师
I want 基于工艺路线自动生成MI草稿
So that 我可以快速创建MI，减少重复工作，确保MI与工艺路线一致
```

**优先级：** P1  
**验收标准：**
- Given 工艺路线已存在
- When 工程师选择工艺路线并创建MI
- Then 系统基于工艺路线的工序自动生成MI指令集列表
- And 工程师可以修改和调整生成的指令集

**相关用例：** UC-ENG-010
