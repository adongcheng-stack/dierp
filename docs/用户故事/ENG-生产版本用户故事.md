# ENG模块 - 生产版本子模块用户故事

**对应菜单：** `/eng/production-versions`  
**对应用例：** UC-ENG-014, UC-ENG-015, UC-ENG-016

---

## US-ENG-014: 创建生产版本

**用户故事：**
```
As an 工程师
I want 创建生产版本，组合BOM、工艺路线和MI
So that 我可以建立完整的生产配置，生产订单可以基于生产版本创建
```

**优先级：** P0  
**验收标准：**
- Given BOM和工艺路线状态为RELEASED
- And BOM和工艺路线准备可以并行进行，无依赖关系
- When 工程师创建生产版本
- Then 系统创建生产版本记录，状态为ACTIVE
- And BOM和工艺路线是必选的
- And MI是可选的（创建时）
- And 只有RELEASED状态的BOM和工艺路线才能用于生产版本
- And 生产版本建立必须等待BOM和工艺路线都准备好
- And 如果任一准备失败，生产版本建立失败，提示用户

**相关用例：** UC-ENG-014

---

## US-ENG-016: 发布生产版本

**用户故事：**
```
As an 工程师
I want 发布生产版本
So that 生产版本可以用于生产订单，确保生产配置完整（包括MI）
```

**优先级：** P0  
**验收标准：**
- Given 生产版本已创建
- And MI已创建且已审核通过
- When 工程师发布生产版本
- Then 系统验证MI已关联且状态为RELEASED
- And 发布生产版本时，MI是必选的
- And 生产版本发布需要MI已制作且MI审核通过
- And 生产版本可以用于生产订单/工单

**相关用例：** UC-ENG-016

- 总计：2个
