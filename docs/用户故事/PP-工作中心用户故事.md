# PP模块 - 工作中心子模块用户故事

**对应菜单：** `/pp/work-centers`  
**对应用例：** UC-PP-001, UC-PP-002

---

## US-PP-001: 创建工作中心

**用户故事：**
```
As an 工程师
I want 创建工作中心，定义生产能力和基础参数
So that 我可以为工艺路线和排产提供工作中心信息
```

**优先级：** P1  
**验收标准：**
- Given 工程师已登录系统
- When 工程师创建工作中心
- Then 系统创建工作中心记录，状态为ACTIVE
- And 工作中心代码必须唯一
- And 系统支持层级结构（父工作中心）
- And 系统支持PCB行业特定属性（工艺类别、技术属性等）

**相关用例：** UC-PP-001

---

## US-PP-002: 更新工作中心

**用户故事：**
```
As an 工程师
I want 更新工作中心信息
So that 我可以维护工作中心的准确信息，确保生产计划准确
```

**优先级：** P2  
**验收标准：**
- Given 工作中心已存在
- When 工程师更新工作中心
- Then 系统更新工作中心记录
- And 工作中心代码不可修改
- And 系统支持更新名称、产能、类型等参数

**相关用例：** UC-PP-002

---

**用户故事统计：**
- P1（高）：1个
- P2（中）：1个
- 总计：2个
