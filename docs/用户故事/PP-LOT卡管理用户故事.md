# PP模块 - LOT卡管理子模块用户故事

**对应菜单：** `/pp/lot-cards`  
**对应用例：** UC-PP-009, UC-PP-009A, UC-PP-009B, UC-PP-009C, UC-PP-009D, UC-PP-009E

---

## US-PP-009: LOT卡管理

**用户故事：**
```
As a 计划员/生产主管
I want 管理LOT卡的全生命周期（查询、查看、编辑）
So that 我可以跟踪生产批次信息，确保生产执行准确
```

**优先级：** P0  
**验收标准：**
- Given 用户已登录系统
- When 用户执行LOT卡管理操作
- Then 系统支持LOT卡查询、列表查看、详情查看、编辑等功能

**相关用例：** UC-PP-009

---

## US-PP-009A: LOT卡生成

**用户故事：**
```
As a 系统
I want 在创建生产订单/工单时自动生成LOT卡
So that 每个生产订单/工单都有对应的批次卡，用于工序报工
```

**优先级：** P0  
**验收标准：**
- Given 生产订单/工单已创建且关联了MI
- When 系统检测到生产订单/工单创建
- Then 系统根据MI自动生成LOT卡
- And 系统自动复制MI内容（mi_content）到LOT卡
- And 系统将lot_number写回生产订单/工单
- And 一个生产订单/工单对应一个LOT卡（1:1关系）
- And 如果MI不存在，不允许创建生产订单/工单或提示用户先创建MI

**相关用例：** UC-PP-009A

## US-PP-009D: LOT卡详情查看

**用户故事：**
```
As a 计划员/生产主管/产线工人
I want 查看LOT卡的详细信息
So that 我可以了解批次的所有信息，包括MI内容、生产信息、关联的报工记录等
```

**优先级：** P0  
**验收标准：**
- Given LOT卡已存在
- When 用户查看LOT卡详情
- Then 系统显示LOT卡的详细信息（LOT卡号、生产订单号、MI编号、物料编码、数量、单位、状态、MI内容、完成时间、备注、关联的报工记录等）

**相关用例：** UC-PP-009D

---

## US-PP-009E: LOT卡编辑

**用户故事：**
```
As a 计划员/生产主管
I want 编辑LOT卡的MI内容和备注
So that 我可以根据实际情况调整批次信息
```

**优先级：** P1  
**验收标准：**
- Given LOT卡已存在
- When 用户编辑LOT卡
- Then 系统将MI内容（mi_content）JSON格式解析为列表
- And 每一条指令/属性项可单独编辑
- And 用户可以编辑备注（remarks）
- And 系统保存编辑后的内容

**相关用例：** UC-PP-009E
