# PP模块 - 工序报工子模块用户故事

**对应菜单：** `/pp/operation-reports`  
**对应用例：** UC-PP-005, UC-PP-006

---

## US-PP-005: 创建工序报工

**用户故事：**
```
As a 生产人员
I want 创建工序报工，记录工序完成情况
So that 系统可以跟踪生产进度，计算生产完成率
```

**优先级：** P0  
**验收标准：**
- Given 生产订单/工单已下达
- When 生产人员创建工序报工
- Then 系统根据生产订单/工单号自动查询关联的LOT卡（1:1关系）
- And 系统自动填充LOT卡号（只读）
- And 如果找不到LOT卡，不允许保存报工
- And 系统创建工序报工记录，状态为PENDING
- And 系统记录报工数量、工时、缺陷等信息

**相关用例：** UC-PP-005

---

## US-PP-006: 更新工序报工

**用户故事：**
```
As a 生产人员
I want 更新已创建的工序报工
So that 我可以修正报工数据，确保数据的准确性
```

**优先级：** P2  
**验收标准：**
- Given 工序报工已创建
- When 生产人员更新工序报工
- Then 系统更新工序报工记录
- And 系统重新计算生产进度
- And 系统重新判断生产订单是否完成
- And 在PENDING/IN_REVIEW状态下可更新报工

**相关用例：** UC-PP-006

---

**用户故事统计：**
- P0（关键）：1个
- P2（中）：1个
- 总计：2个
