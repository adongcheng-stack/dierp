# PP模块 - 工单管理子模块用户故事

**对应菜单：** `/pp/production-orders`  
**对应用例：** UC-PP-003, UC-PP-004, UC-PP-004A, UC-PP-007, UC-PP-008, UC-PP-010

**说明：** 生产订单在实现中同时承担工单职责，当前版本不单独建WorkOrder表。

---

## US-PP-003: 创建生产订单

**用户故事：**
```
As a 计划员/生产人员
I want 创建生产订单/工单
So that 我可以将销售订单转化为生产任务，启动生产流程
```

**优先级：** P0  
**验收标准：**
- Given 销售订单已审批通过
- When 计划员创建生产订单/工单
- Then 系统创建生产订单记录，状态为DRAFT
- And 系统关联销售订单和生产版本
- And 如果关联了MI，系统根据MI自动生成LOT卡（1:1关系）
- And 系统支持单位转换（销售单位、生产单位、转换系数）

**相关用例：** UC-PP-003

---

## US-PP-004: 下达生产订单/工单

**用户故事：**
```
As a 计划员
I want 下达生产订单/工单
So that 生产订单可以进入生产执行阶段
```

**优先级：** P0  
**验收标准：**
- Given 生产订单状态为DRAFT
- And 生产版本已发布
- And MI已审核通过
- When 计划员下达生产订单/工单
- Then 生产订单状态更新为RELEASED
- And 系统记录下达时间和下达人

**相关用例：** UC-PP-004

---

## US-PP-004A: 开始生产

**用户故事：**
```
As a 计划员/生产人员
I want 开始生产订单/工单
So that 生产订单可以进入生产执行状态，系统可以跟踪生产进度
```

**优先级：** P0  
**验收标准：**
- Given 生产订单状态为RELEASED
- When 计划员或生产人员开始生产
- Then 生产订单状态更新为IN_PRODUCTION
- And 系统记录实际开始时间
- And 系统同步销售订单状态

**相关用例：** UC-PP-004A

---

## US-PP-007: 完成生产订单/工单

**用户故事：**
```
As a 系统/生产人员
I want 完成生产订单/工单（自动或手动）
So that 生产订单/工单可以进入完成状态，销售订单状态可以同步更新
```

**优先级：** P0  
**验收标准：**
- Given 所有工序都已报工完成
- When 系统自动完成或生产人员手动完成生产订单/工单
- Then 生产订单/工单状态更新为COMPLETED
- And 系统记录实际完成日期
- And 系统同步销售订单状态（如果所有生产订单/工单都已完成，销售订单状态更新为COMPLETED）
- And 由于生产订单承担工单职责，工单状态与生产订单状态一致

**相关用例：** UC-PP-007

---

## US-PP-008: 关闭生产订单/工单

**用户故事：**
```
As a 计划员
I want 关闭生产订单/工单
So that 生产订单/工单可以结束生命周期，系统可以清理相关资源
```

**优先级：** P2  
**验收标准：**
- Given 生产订单/工单状态为RELEASED、IN_PRODUCTION或COMPLETED
- When 计划员关闭生产订单/工单
- Then 生产订单/工单状态更新为CLOSED
- And 系统记录实际完成时间和关闭时间
- And 系统同步销售订单状态（如果所有生产订单/工单都已完成或已关闭，销售订单状态更新为COMPLETED）
- And 销售订单关闭时，关联的生产订单/工单也会自动关闭
- And 由于生产订单承担工单职责，工单状态与生产订单状态一致

**相关用例：** UC-PP-008

---

## US-PP-010: 生产进度查看

**用户故事：**
```
As a 计划员/生产主管
I want 查看生产进度
So that 我可以了解生产订单的执行情况，及时发现问题
```

**优先级：** P0  
**验收标准：**
- Given 生产订单已创建
- When 用户查看生产进度
- Then 系统显示订单状态、工序完成率、报工情况、LOT卡状态等

**相关用例：** UC-PP-010
