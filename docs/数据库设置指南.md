# 数据库设置指南

## 前提条件

1. **PostgreSQL已安装**
   - 下载地址：https://www.postgresql.org/download/windows/
   - 安装时记住设置的postgres用户密码

2. **PostgreSQL服务正在运行**
   - Windows: 在"服务"中检查"postgresql-x64-xx"服务是否运行
   - 或使用命令：`Get-Service | Where-Object {$_.Name -like "*postgresql*"}`

## 方法1：使用Python脚本自动创建（推荐）

### 步骤1：创建数据库

```powershell
cd backend
python create_database.py
```

这个脚本会：
- 自动连接到PostgreSQL服务器
- 检查数据库是否已存在
- 如果不存在则创建 `hserp_mvp` 数据库

### 步骤2：初始化数据库表

```powershell
python init_db.py
```

这个脚本会：
- 创建所有数据表
- 创建默认管理员用户（admin/admin123）

## 方法2：使用psql命令行工具

### 找到psql路径

PostgreSQL安装后，psql通常在以下位置：
```
C:\Program Files\PostgreSQL\<version>\bin\psql.exe
```

### 使用psql创建数据库

```powershell
# 方法A: 使用完整路径
& "C:\Program Files\PostgreSQL\16\bin\psql.exe" -U postgres -c "CREATE DATABASE hserp_mvp;"

# 方法B: 将PostgreSQL bin目录添加到PATH环境变量
# 然后直接使用
psql -U postgres -c "CREATE DATABASE hserp_mvp;"
```

### 交互式连接

```powershell
psql -U postgres
```

然后在psql提示符下执行：
```sql
CREATE DATABASE hserp_mvp;
\q
```

## 方法3：使用pgAdmin（图形界面）

1. 打开pgAdmin
2. 连接到PostgreSQL服务器
3. 右键点击"Databases" → "Create" → "Database"
4. 输入数据库名：`hserp_mvp`
5. 点击"Save"

## 配置数据库连接

创建数据库后，确保 `backend/.env` 文件中的连接信息正确：

```env
DATABASE_URL=postgresql://postgres:你的密码@localhost:5432/hserp_mvp
```

**重要：** 将 `你的密码` 替换为PostgreSQL的postgres用户密码。

## 验证数据库

### 检查数据库是否创建成功

使用Python脚本：
```powershell
python -c "import psycopg2; conn = psycopg2.connect('postgresql://postgres:你的密码@localhost:5432/hserp_mvp'); print('连接成功！'); conn.close()"
```

使用psql：
```powershell
psql -U postgres -d hserp_mvp -c "\dt"
```

## 常见问题

### 问题1: "psql: 无法识别"

**原因：** psql不在系统PATH中

**解决：**
1. 找到PostgreSQL安装目录下的bin文件夹
2. 添加到系统PATH环境变量
3. 或使用完整路径调用psql

### 问题2: "密码认证失败"

**原因：** 密码不正确

**解决：**
1. 检查 `.env` 文件中的密码
2. 或重置PostgreSQL密码

### 问题3: "无法连接到服务器"

**原因：** PostgreSQL服务未运行

**解决：**
```powershell
# 检查服务状态
Get-Service | Where-Object {$_.Name -like "*postgresql*"}

# 启动服务（需要管理员权限）
Start-Service postgresql-x64-16
```

### 问题4: "数据库已存在"

**解决：** 这是正常的，可以继续执行 `init_db.py`

## 完整设置流程

```powershell
# 1. 进入backend目录
cd backend

# 2. 创建.env文件（如果不存在）
# 编辑.env，设置正确的数据库连接信息

# 3. 创建数据库
python create_database.py

# 4. 初始化数据库表
python init_db.py

# 5. 启动后端服务
.\start.ps1
```

## 重置数据库

如果需要重新开始：

```sql
-- 使用psql连接
psql -U postgres

-- 删除数据库
DROP DATABASE hserp_mvp;

-- 重新创建
CREATE DATABASE hserp_mvp;
\q
```

然后重新运行 `init_db.py`。
